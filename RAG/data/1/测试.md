# 轻记（QingJi）项目技术总结

## 项目概况
轻记是一款 iOS 记账应用，使用 SwiftUI + SwiftData 开发，由独立开发者阿风完成从功能设计到开发实现的全流程。项目里程碑 M1 到 M5 已全部完成，当前处于收尾阶段。

## 技术栈
- 界面层：SwiftUI
- 数据层：SwiftData 本地持久化
- 云同步：CloudKit（受阻于付费开发者账号尚未到位）
- 平台：macOS + Xcode 开发环境

## CloudKit 同步方案
轻记的云同步基于 CloudKit，需要在付费开发者账号开通后才能继续验证与上线。同步策略采用记录级冲突解决，本地优先写入，后台异步上传至 iCloud 私有数据库。

## 记账核心模型
一笔账目记录包含以下字段：金额、分类、日期、备注、支付方式。月度统计视图按分类聚合金额，支持同比环比对比。
